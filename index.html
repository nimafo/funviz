Telegram Chat Heatmap

Turn a Telegram chat into a GitHub-style heatmap of messages per day. Your file never leaves your browser.

1. Export your chat from Telegram
  1. Install Telegram Desktop (the phone apps can't export).
  2. Open the chat you want and click ⋮ in the top-right corner → Export chat history.
  3. Untick photos, videos, files, etc. Only the text is needed, so the export is much faster.
  4. Set Format to Machine-readable JSON.
  5. Make sure the date range is From: the oldest message, then click Export.
  6. Find result.json in Downloads/Telegram Desktop/ChatExport_….

A full-account export (Settings → Advanced → Export Telegram data, JSON) works too. You'll get a list of chats to choose from.

2. Drop result.json here

Drag & drop result.json or click to choose a file · processed locally, nothing is uploaded

No export handy? Try it with random demo data.

3. Customize & download

Everything runs in your browser. Your chats are never uploaded. Only an anonymous usage counter is sent. · Source on GitHub
